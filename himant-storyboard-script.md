# हिमंत (HIMANT) — STORYBOARD PRODUCTION SCRIPT
### Every Shot | Image Generation Prompts | Character Positions | Dialogue | Music
### Format: Generate Image → Add Text/Dialogue → Add Music → Connect to Next Shot → Video

---

# HOW TO USE THIS DOCUMENT

Each SHOT = One image you generate in Midjourney / Flux / Stable Diffusion
1. Copy the IMAGE PROMPT exactly → paste into your AI image tool
2. Check CHARACTER POSITIONS — arrange/edit if needed
3. Add DIALOGUE as text overlay or voiceover
4. Add MUSIC from the Suno prompt
5. Hold the image for the DURATION listed
6. Cut to the next shot

| Shot Type | Minimum Hold | Maximum Hold |
|-----------|-------------|--------------|

| Scene Type | Color Grade |
|-----------|-------------|

| Vriddhak scenes | Neutral, slightly green-grey, controlled |
